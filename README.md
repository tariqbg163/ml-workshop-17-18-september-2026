# Machine Learning Workshop — September 17–18, 2026

Welcome to the **Machine Learning Workshop** repository.

This repository contains the lecture materials, notebooks, code examples, datasets, and practical exercises covered during the workshop on **September 17–18, 2026**.

The workshop introduces participants to the fundamental concepts of Machine Learning and provides hands-on exposure to different Machine Learning paradigms.

By the end of the workshop, participants should be able to:

* Understand the fundamentals of Machine Learning.
* Differentiate between supervised, unsupervised, and reinforcement learning.
* Understand the basic Machine Learning workflow.

* Encode categorical variables.
* Apply feature scaling.
* Perform basic Exploratory Data Analysis.

# 💻 Installation

## Clone the Repository

```bash
git clone https://github.com/tariqbg163/ml-workshop-17-18-september-2026.git
```

## Navigate to the Repository

```bash
cd ml-workshop-17-18-september-2026
```

## Create a Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux/macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Launch Jupyter Notebook

```bash
jupyter notebook
```
